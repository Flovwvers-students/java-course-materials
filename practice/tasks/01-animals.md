# Задача 1 — Животные

### Документация

Программа предназначена для работы с животными.

У каждого животного есть имя. Базовый тип животного должен предоставлять стандартное поведение, которое можно использовать, если для конкретного животного оно не определено.

Для собак должно быть предусмотрено собственное поведение: собака должна издавать характерный для неё звук.

При создании собаки её имя должно сохраняться и корректно отображаться при выводе информации.

Также программа должна позволять работать с собакой через тип обычного животного. При этом специальное поведение собаки не должно теряться.

### Жалобы клиентов

> «Мы запустили программу, но она вообще не собирается».

> «После исправления одной ошибки имя собаки всё равно нормально не используется внутри программы».

> «Почему-то непонятно, действительно ли программа использует поведение собаки, когда переменная объявлена как обычное животное».
