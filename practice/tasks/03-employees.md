# Задача 3 — Сотрудники

### Документация

Программа предназначена для расчёта выплат сотрудникам компании.

У каждого сотрудника есть имя и базовая зарплата.

Сотрудники разных специальностей получают разные бонусы. Разработчик получает один размер бонуса, дизайнер — другой.

Расчёт дополнительной выплаты должен выполняться с учётом конкретной специальности сотрудника.

При выводе информации должна отображаться корректная зарплата сотрудника.

Объекты сотрудников должны обрабатываться через общий тип сотрудника, сохраняя специальное поведение каждого конкретного типа.

### Жалобы клиентов

> «У всех сотрудников после создания зарплата почему-то получается нулевой».

> «Для разработчика программа не может нормально рассчитать бонус».

> «При добавлении дизайнера компилятор ругается на его переопределение метода».

> «Мы рассчитываем зарплату через общий тип сотрудника и не понимаем, почему результат не соответствует ожидаемому».
