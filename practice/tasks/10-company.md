# Задача 10 — Компания

### Документация

Программа предназначена для учёта сотрудников компании.

У каждого сотрудника есть имя и базовая зарплата.

Разные специалисты могут иметь разные правила расчёта итоговой выплаты.

Компания содержит набор сотрудников и должна рассчитывать общую сумму выплат всем сотрудникам.

Также необходимо уметь находить сотрудника по имени.

Компания должна вести общее количество созданных объектов компании.

При работе с сотрудниками через общий тип необходимо сохранять возможность использовать их специализированный расчёт выплаты.

### Жалобы клиентов

> «Компания показывает только базовые зарплаты, хотя сотрудникам положены дополнительные выплаты».

> «Поиск сотрудника по имени иногда не находит существующего человека».

> «Количество созданных компаний неожиданно не совпадает с реальным».

> «Мы передаём сотрудников через общий тип, но итоговая сумма выплат получается такой, будто специальных правил для должностей нет».
