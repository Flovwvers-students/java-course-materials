# Кодстайл Java

[Действующие требования](Java_Code_Style.txt) — с уточнениями преподавателя 26–31.10.2026.

- №1: послабление по стилю. №2 и далее: проверяем стиль, компиляцию и логику одновременно.
- x/y/z допустимы для координат.
- Одноразовые понятные сообщения и форматы допустимы в месте использования; повторяющиеся строки и общие настройки формата — в константы.
- Именованные числа и остальные правила сохраняются.

[Первоначальный документ рассылки](original/java_code_style.docx) сохранён без изменения как источник. Его прежние формулировки о возврате без логики и любых строках применяются с перечисленными уточнениями.
